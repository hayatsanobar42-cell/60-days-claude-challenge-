Day 18 – Brain Dump Action Planner Skill

Objective

Designed a custom Claude Skill to convert unstructured notes into actionable plans and interactive HTML dashboards.

Skill Name

brain-dump-action-planner

Description

Transform messy notes, meeting transcripts, voice memos, brainstorming sessions, and stream-of-consciousness thoughts into structured summaries, action plans, decisions, open questions, and task lists.

Planned Features

- Self-contained HTML dashboard output
- Summary and key takeaways
- Action items with owners and deadlines
- Risks and blockers
- Conflict detection
- Transcript mode support
- Merge mode support
- Ultra-strict source fidelity
