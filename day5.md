# 30-Day Data Science Learning Roadmap 🚀

## 🎯 Your Learning Journey

**Goal:** Build foundational Data Science skills with hands-on projects

**Final Outcome:** Portfolio-ready projects + foundational Data Science knowledge

## 📚 WEEK 1: Python Fundamentals & Environment Setup

### Weekly Goal
Set up your development environment and master Python basics needed for data science.

### Day 1-2: Setup & Python Basics
**Daily Time:** 1-1.5 hours

**Tasks:**
- [ ] Install Anaconda/Python 3.9+
- [ ] Set up Jupyter Notebook
- [ ] Learn: Variables, data types, basic operations
- [ ] Code along: 10-15 simple Python exercises

**Resources:**
- Anaconda Installation: https://www.anaconda.com/products/individual
- **Video:** Python for Data Science (Kaggle Learn) - 5 min intro
- **Free Course:** DataCamp Python Basics (Interactive, 1 hour)

**Project Starter:** "My First Python Program"
```python
# Create a simple calculator that tracks expenses
```

---

### Day 3-4: Data Types & Functions
**Daily Time:** 1-2 hours

**Tasks:**
- [ ] Master lists, dictionaries, tuples
- [ ] Understand functions and parameters
- [ ] Practice with 20+ coding exercises
- [ ] Build: Simple function-based expense tracker

**Resources:**
- **Video:** Python Functions (YouTube: Corey Schafer) - 20 min
- **Interactive:** W3Schools Python Tutorial
- **Practice:** LeetCode Easy Problems (5-10 problems)

**Mini Project:** "Expense Tracker v1"
```
Input expenses → Store in list → Calculate total
```

---

### Day 5-7: Control Flow & File Handling
**Daily Time:** 1-2 hours

**Tasks:**
- [ ] Master if/else, loops (for, while)
- [ ] File reading and writing
- [ ] Error handling basics
- [ ] Refactor expense tracker to use files

**Resources:**
- **Video:** Python Control Flow (10 min)
- **Practice:** 15 coding exercises on loops
- **Documentation:** Python Official Docs (reference)

**Project Milestone:** "Expense Tracker v2"
```
Read expenses from file → Process → Save results
```

---

## 📊 WEEK 2: Data Analysis with Pandas

### Weekly Goal
Load, clean, explore, and analyze real datasets using Pandas.

### Day 8-9: Pandas Basics & Data Loading
**Daily Time:** 1.5-2 hours

**Tasks:**
- [ ] Install & import Pandas
- [ ] Load CSV files
- [ ] Understand DataFrames and Series
- [ ] Explore data with `.head()`, `.info()`, `.describe()`

**Resources:**
- **Kaggle Learn:** Pandas (30 min course, highly recommended)
- **Video:** Pandas Tutorial (Corey Schafer) - 30 min
- **Dataset Source:** Kaggle.com (beginner-friendly datasets)

**Project Starter:** "EDA (Exploratory Data Analysis) - Student Grades"
```
Load CSV → Display first rows → Basic statistics
```

---

### Day 10-11: Data Cleaning & Transformation
**Daily Time:** 1.5-2 hours

**Tasks:**
- [ ] Handle missing values
- [ ] Remove duplicates
- [ ] Filter and select columns
- [ ] Create new columns from existing data

**Resources:**
- **Tutorial:** Data Cleaning with Pandas
- **Practice Dataset:** House Prices or Iris Dataset

**Project Update:** "Clean Student Grades Dataset"
```
Identify missing data → Fill/remove → Create GPA column
```

---

### Day 12-14: Data Analysis & Grouping
**Daily Time:** 1.5-2 hours

**Tasks:**
- [ ] Group data with `.groupby()`
- [ ] Aggregate data (sum, mean, count)
- [ ] Merge/join datasets
- [ ] Create pivot tables
- [ ] Generate summary statistics

**Resources:**
- **Video:** Pandas GroupBy (15 min)
- **Interactive:** Mode Analytics SQL/Pandas Tutorial
- **Practice:** Real CSV files from Kaggle

**Project Submission:** "Grade Analysis Report"
```
Deliverables:
- Average grade by class
- Top 10 students
- Grade distribution analysis
- Final summary report
```

## 📈 WEEK 3: Data Visualization

Create clear, professional visualizations to communicate insights.

### Day 15-16: Matplotlib Basics
**Daily Time:** 1.5-2 hours

**Tasks:**
- [ ] Install & import Matplotlib
- [ ] Create line plots, bar charts, scatter plots
- [ ] Customize colors, labels, titles
- [ ] Understand figure and axes objects

**Resources:**
- **Kaggle Learn:** Data Visualization (25 min)

**Mini Project:** "Visualize Grade Data"
```

```

---

### Day 17-18: Seaborn & Advanced Plots
**Daily Time:** 1.5-2 hours

**Tasks:**
- [ ] Learn Seaborn library (builds on Matplotlib)
- [ ] Create heatmaps, box plots, violin plots
- [ ] Multi-plot grids
- [ ] Statistical visualizations

**Resources:**
- **Kaggle Learn:** Seaborn (15 min)
- **Documentation:** Seaborn Gallery
- **Video:** Seaborn Tutorial (20 min)

**Project Practice:** "Multi-plot Analysis"
```
Create 4-6 different chart types for one dataset
```

---

### Day 19-21: Data Storytelling with Visualizations
**Daily Time:** 1.5-2 hours

**Tasks:**
- [ ] Create a multi-visualization dashboard
- [ ] Write narrative around charts
- [ ] Design for clarity and impact
- [ ] Combine Pandas + Matplotlib/Seaborn

**Resources:**
- **Best Practices:** Edward Tufte Principles
- **Inspiration:** DataViz Best Practices

**Project Delivery:** "Interactive Data Story"
```
Create a report with 5-8 visualizations telling a story
about a real dataset (grades, sales, weather, etc.)
```

## 💡 Tips for Success

### Stay Motivated
- ✨ Celebrate small wins daily
- 📊 Share progress on social media
- 👥 Join data science communities (Reddit: r/datascience)
- 🎯 Keep your goal visible

### Stay on Track
- 📅 Set a fixed study time each day
- 📱 Eliminate distractions (phone away)
- 📝 Take handwritten notes

### Problem-Solving
- 🔍 Google the error message first
- 💬 Ask in Discord/Slack communities

- 🧪 Test small code snippets first
