# Day 48 – Build The Verdict Engine

## 🎯 Objective
Build an AI-powered Verdict Engine that compares multiple Data Analytics certifications using weighted decision criteria and helps users make informed decisions with transparent, research-backed insights.

---

## 🚀 Features
- Compare 4 popular Data Analytics credentials
- Fixed Ranking mode
- Custom Weight mode with live re-ranking
- Interactive comparison table
- Research-backed scoring
- Sources panel
- "How this was researched" section
- Responsive and modern UI
