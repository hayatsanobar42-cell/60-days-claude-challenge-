# Day 20 – AI Face Puzzle Game

## Objective

Build an interactive face puzzle game using HTML, CSS, JavaScript, and Claude AI.

## Features Implemented

- Webcam integration
- Photo capture functionality
- Multiple difficulty levels (3×3, 4×4, 5×5)
- Drag-and-drop support
- Touch interaction support
- Timer and move counter
- Automatic completion detection
- Leaderboard using localStorage
- Responsive UI design

## Tools Used

- Claude AI
- HTML5
- CSS3
- JavaScript
- Browser Camera API
- localStorage

## Learnings

- Working with webcam APIs
- Image processing using canvas
- Implementing drag-and-drop interactions
- Managing game state with JavaScript
- Persisting data using localStorage
- Creating responsive browser games

## Challenges Faced

- Handling touch interactions on mobile devices
- Splitting captured images accurately
- Ensuring puzzle completion detection works correctly

## Outcome

Successfully built a browser-based AI Face Puzzle Game that allows users to capture their own photos and solve interactive puzzles.
