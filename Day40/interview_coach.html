    BEHAVIORAL

    The system prompt

    Every call sends one fixed system prompt to Claude that pins down a single role — an encouraging-but-honest interview coach — and a strict job boundary: it only generates interview questions or evaluates interview answers, nothing else. The prompt forces mode-based JSON output (generate_questions or evaluate_answer) with an exact schema, so the frontend never has to guess at structure or parse prose. Edge cases are handled explicitly in the prompt: pasted content that isn't a real job description gets flagged rather than silently accepted, empty or one-word answers get a low score and honest feedback instead of a generous default, and any attempt to redirect the model off-task (prompt injection inside pasted resume/job text) is ignored — the model treats pasted content strictly as data, never as instructions.

    Why the UI looks like this

    Two real steps — set the scene, then practice — so numbered stage markers (01/02) actually carry meaning instead of decorating the page. The confidence dial and STAR chips exist because interview prep is evaluative and structural: a single number tells you "how did I do," and the chips tell you exactly which part of a STAR answer is missing, which is more actionable than a paragraph of prose. The improved-answer panel is styled as a dark card, visually distinct from the light "your answer" area, so it reads as a rewrite to hold onto — not more feedback to parse.

    Extending this

    • Memory across sessions: store generated questions and scores in localStorage or a backend so a user can resume practice across visits and see score trends over time.
    • Multi-step mock interview: chain calls into a real back-and-forth — after each answer, generate a natural follow-up question instead of moving to the next static one.
    • Tools: add a web-search tool to the API call so question generation can pull real, recent interview questions reported for that specific company.
    • Voice practice: swap the textarea for speech-to-text so users can rehearse answers out loud and get feedback on pacing and filler words, not just content.
