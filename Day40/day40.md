# Day 40 - Build Your Own AI Assistant

## Project Title
Interview Answer Coach

## Domain
Career, Resume & Job Tools

## Target Audience
Job seekers preparing for a specific upcoming interview.

## Project Description
Interview Answer Coach is an AI-powered web application that helps candidates prepare for job interviews. Users can paste a job description and their resume to receive likely interview questions. The assistant evaluates answers, provides a score, suggests improved responses, and explains how to make answers stronger.

## Features
- AI-generated interview questions
- Resume and Job Description analysis
- Answer scoring
- Improved answer suggestions
- Feedback with reasoning
- Responsive HTML interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Claude AI

## Key Learnings
- Prompt Engineering
- AI Assistant Design
- System Prompting
- Frontend Development
- Building AI-powered applications

## Challenges
- Understanding prompt design
- Integrating AI-generated responses
- Testing the application

## Outcome
Built an Interview Answer Coach that assists users in preparing for interviews by generating questions and providing feedback on their answers.
