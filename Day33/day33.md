# Day 33 – Media Integrity Analyzer

## Objective
Built an interactive Media Integrity Analyzer that helps users evaluate news headlines, detect emotional manipulation, analyze media bias, assess source reliability, and improve media literacy through engaging challenges.

## Features
- Headline Integrity Analyzer
- Emotion Detection
- Manipulation Technique Detector
- Source Reliability Ratings
- Fake News Challenge
- Learning Center
- Analytics Dashboard
- Multiple Themes
- Responsive UI
- Smooth Animations

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Learning Outcomes
- Media literacy concepts
- UI dashboard design
- Interactive data visualization
- DOM manipulation
- Responsive frontend development
