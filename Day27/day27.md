# Day 27 – Prior Authorization Story Simulator

## Objective
Built an interactive Prior Authorization Story Simulator to understand the US healthcare prior authorization workflow through a story-based experience.

## Features
- Interactive healthcare story
- 8 story chapters
- Patient, Provider, and Payer workflow
- Progress tracker
- Decision-based branching
- Responsive UI
- Pure HTML, CSS, and JavaScript

## What I Learned
- Prior Authorization workflow
- Interactive storytelling
- State management in JavaScript
- UI/UX for educational simulations
- Building single-file web applications
