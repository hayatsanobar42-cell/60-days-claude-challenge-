# Day 51 - Product Discovery & Sprint Planning 🚀

## Project Name
**CareerCompass AI**

## Project Overview
CareerCompass AI is an AI-powered career readiness platform designed for engineering students and freshers. It helps users analyze their resumes, identify skill gaps, improve ATS compatibility, and receive personalized career roadmaps.

## Problem Statement
Many students and freshers struggle with:
- Creating ATS-friendly resumes
- Understanding missing skills for their target roles
- Knowing what to learn next for career growth
- Preparing effectively for internships and placements

## Target Audience
Primary users:
- Engineering students preparing for internships and campus placements

Secondary users:
- Recent graduates (freshers) looking for their first job opportunities

## Core Features (MVP)

### 1. ATS Resume Analyzer
- Users paste their resume text
- Calculates ATS score
- Checks keyword matching
- Identifies missing keywords and skills

### 2. Skill Gap Analyzer
- Compares current skills with target role requirements
- Highlights missing skills
- Provides improvement suggestions

### 3. Personalized Career Roadmap
- Generates a learning roadmap based on identified skill gaps
- Suggests skills to learn in priority order

## Supported Roles (v1.0)
- Data Analyst
- Software Engineer
- Frontend Web Developer
- Business Analyst

## Technical Decisions

### Resume Input
- Text-based resume input for v1.0
- PDF/DOCX upload planned for future versions

### ATS Scoring Approach
Combination of:
- Keyword matching
- Resume section checks
- Basic formatting evaluation

### Data Storage
- Browser localStorage
- No authentication/database in MVP

## Tech Stack
- HTML
- CSS
- JavaScript
- Python (for analysis logic)
- Git/GitHub

## MVP Scope
Focus on building a polished and functional product within 10 days.

### Not Included in v1.0
- User authentication
- Cloud database
- PDF parsing
- Mobile application
- Advanced AI API integration

## Success Criteria
A user should be able to:
1. Enter resume details
2. Select a target role
3. Receive ATS score
4. View skill gaps
5. Get a personalized career roadmap
