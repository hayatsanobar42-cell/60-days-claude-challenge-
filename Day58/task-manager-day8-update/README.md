# Simple Task Manager

A beginner-friendly task manager web app built with plain HTML, CSS, and JavaScript. No frameworks, no build tools, no paid services — just a clean, fast, responsive to-do list that persists your tasks in the browser.

**🌐 Live demo:** https://hayatsanobar42-cell.github.io/task-manager/

## Features
- Add, complete, and delete tasks
- Tasks persist automatically via `localStorage`
- Fully responsive — works well on phones, tablets, and desktop
- Accessible: keyboard focus states, aria-labels, respects reduced-motion preference
- Production-hardened: validates and recovers from corrupted stored data, warns the user if saving fails, collision-safe task IDs, race-condition-safe delete
- Zero dependencies, zero cost to run or host

## How to run
1. Clone this repository.
2. Open `index.html` in your browser (or use the "Live Server" VS Code extension).
