# Day 17 – AI Vehicle Cost & Fuel Analysis Dashboard

## Objective

Built an AI-powered dashboard to analyze vehicle ownership costs, fuel expenses, maintenance costs, and E85 fuel economics.

## Tools Used

- Claude AI
- HTML
- CSS
- JavaScript
- Chart.js
- GitHub

## Process

1. Downloaded the provided CSV dataset.
2. Uploaded the dataset to Claude.
3. Added vehicle details.
4. Generated a responsive HTML dashboard.
5. Analyzed fuel costs and maintenance expenses.
6. Reviewed E85 break-even calculations.
7. Captured dashboard screenshots.
8. Uploaded files to GitHub.

## Key Insights

- E85 fuel offers lower fuel costs but reduced mileage.
- Total ownership cost depends on annual distance traveled.
- Break-even point varies with fuel price fluctuations.
- Environmental impact is reduced when using E85.
